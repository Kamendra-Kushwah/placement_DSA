## Problem Statement
Given an array `arr[]`. The task is to find the largest element and return it.

---

## Examples

**Input:**  
`arr[] = [1, 8, 7, 56, 90]`  
**Output:**  
`90`  
**Explanation:** The largest element of the given array is 90.

**Input:**  
`arr[] = [5, 5, 5, 5]`  
**Output:**  
`5`  
**Explanation:** All elements are equal, so the largest is 5.

**Input:**  
`arr[] = [10]`  
**Output:**  
`10`  
**Explanation:** Only one element, hence it is the largest.

---

## Constraints
- \(1 \leq arr.size() \leq 10^6\)  
- \(0 \leq arr[i] \leq 10^6\)

---

## Expected Complexities
- **Time Complexity:** \(O(n)\)  
- **Auxiliary Space:** \(O(1)\)
